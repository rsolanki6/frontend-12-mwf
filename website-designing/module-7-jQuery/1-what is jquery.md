# What is jQuery?
1. jquery is a client side scripting language
2. jquery ia a library of javascript
3. jquery is also called inside of <head> and <body> using script tag
4. jquery is called via its **CDN (Content Delivery Network)**
  
     ## There are 2 type od CDN
     1. offline CDN
     2. Online CDN

5. jwuery starter using its method...
``` javascript

     <script>
          $(document).ready(function(){
               statement;
          })
     </script>

     or

     <script>
          jQuery(document).ready(function(){
               statement;
          })
     </script>


```
